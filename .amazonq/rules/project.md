# Project: Kalkulator KPR

Single Page Application — KPR (mortgage) calculator with annuity interest scheme and tiered tenor.

## Tech Stack
- React 18 + TypeScript (strict mode) + Vite
- Tailwind CSS v3
- xlsx (export to XLSX)
- jspdf + jspdf-autotable (export to PDF)

## Constraints
- Fully client-side, no server or API calls
- No test framework configured — do not add tests unless explicitly asked
- No routing library — single page, single component tree
- UI language: Bahasa Indonesia
